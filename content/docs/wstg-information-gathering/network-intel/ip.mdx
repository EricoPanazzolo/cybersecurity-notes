General host/IP intelligence via Censys Search.

## Tools

### Censys Search

[search.censys.io](https://search.censys.io/) — a search engine that indexes internet-facing hosts and their exposed
services/certificates. Useful for finding all hosts using a specific
certificate, open service, or banner across the entire internet — good for
asset discovery and finding shadow IT.

See [Cloudflare](/docs/wstg-configuration-management/cloudflare) for a Censys
Search query built on this tool that finds a target's real origin IP behind
Cloudflare.

See [Whois](/docs/wstg-information-gathering/network-intel/whois) for basic IP/DNS info bundled
into a domain's WHOIS record.
