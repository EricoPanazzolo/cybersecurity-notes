<Callout type="info" title="Playbook">
  This recipe chains [Nmap](/docs/wstg-information-gathering/fingerprinting/nmap) with **nmap2html** — a
  standalone Python tool that turns Nmap's XML output into a clean,
  interactive, self-contained HTML report, no server or dependencies
  required. Relates to **WSTG-INFO-02** (Fingerprint Web Server).
</Callout>

## Step 1 — Scan with Nmap, save XML output

<CommandInput
  vars={{ target: "10.10.10.10" }}
  derivedVars={{ output: { from: "target", template: "nmap_{value}.xml" } }}
  publishChannel="nmap-xml"
  command={`nmap -sV -sC -A {{target}} -oX {{output}}`}
  placeholderMode
/>

`-oX` is required — nmap2html only reads Nmap's XML output, not the
plain-text or grepable formats.

<Callout type="info">
  Scanning multiple targets from a file also works — see
  [Nmap's flag reference](/docs/wstg-information-gathering/fingerprinting/nmap) for `-iL`.
</Callout>

## Step 2 — Generate the HTML report

`input` tracks Step 1's `output` field above live — edit it directly here
to break the link.

<CommandInput
  vars={{ input: "nmap_10.10.10.10.xml" }}
  derivedVars={{ input: { channel: "nmap-xml" } }}
  command={`python3 nmap2html.py {{input}}`}
  placeholderMode
/>

By default this writes `<name>.html` next to the input file, plus
`assets/report.css` and `assets/report.js`. Pass `-o` to choose the output
file instead:

<CommandInput
  vars={{ input: "nmap_10.10.10.10.xml" }}
  derivedVars={{
    input: { channel: "nmap-xml" },
    output: { from: "input", template: "{stem}.html" },
  }}
  command={`python3 nmap2html.py {{input}} -o {{output}}`}
  placeholderMode
/>

## What you get

- A single self-contained HTML report — no server, no external
  dependencies, just open it in a browser.
- Detail and sheet views for browsing scan results.
- Review tracking via the browser's `localStorage`.
- Clickable links for any HTTP/HTTPS service Nmap found.

Requires Python 3.9+ and Nmap itself — no third-party Python packages.
