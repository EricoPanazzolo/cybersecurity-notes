title: Gobuster

**Gobuster** is a Go-based brute-forcing tool used to discover hidden
directories/files on web servers, virtual hosts, and more — by trying every
entry in a wordlist against the target.

<Callout type="info">
  Gobuster's `dns` mode (subdomain brute-forcing) is covered on the
  [Subdomain & Attack Surface Discovery](/docs/subdomain-discovery/gobuster-dns)
  page instead, alongside the other subdomain enumeration tools.
</Callout>

## Directory / file brute-force

<CommandInput
  vars={{ website: "https://target.com" }}
  command={`gobuster dir -u {{website}} -w /usr/share/SecLists/Discovery/Web-Content/directory-list-2.3-medium.txt -o dir_list.txt`}
/>

## Flag reference

| Flag | Meaning |
| --- | --- |
| `dir` | Mode: brute-force directories/files on a web server. |
| `-u <website>` | Target base URL. |
| `-w <wordlist>` | Path to the wordlist to brute-force with. |
| `-o <file>` | Writes results to a file instead of (or in addition to) stdout. |

## Other useful flags (not in the original notes)

| Flag | Meaning |
| --- | --- |
| `-x <ext,ext>` | Append file extensions to try (e.g. `-x php,txt,bak`). |
| `-t <n>` | Number of concurrent threads (default 10). |
| `-k` | Skip TLS certificate verification (useful for self-signed certs). |
| `-r` | Follow redirects. |
| `-s <codes>` | Only show responses with these status codes. |

<Callout type="info">
  SecLists ships a wordlist for this under `Discovery/Web-Content/`. Combine
  with tools like [Amass](/docs/subdomain-discovery/amass) or
  [BBOT](/docs/subdomain-discovery/bbot) for broader passive coverage.
</Callout>
