**SecLists** is the standard wordlist collection used across almost every
tool on this site (directories, subdomains, parameters, etc.).

## Install

```bash
cd /usr/share/wordlists && git clone https://github.com/danielmiessler/SecLists
```

## Notes

Many tool pages in this reference reference paths under
`/usr/share/SecLists/...` or `/usr/share/wordlists/SecLists/...` — adjust to
wherever you cloned it (e.g. `/opt/SecLists`).
