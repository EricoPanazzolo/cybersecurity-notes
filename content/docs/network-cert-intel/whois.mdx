Looking up a domain's registration details: registrar, creation/expiry
dates, and name servers.

## Tools

### [Who.is](https://who.is/)

WHOIS lookup service — returns domain registration details (registrar,
creation/expiry date, name servers) and basic IP/DNS info for a domain or
IP.

## Quick CLI equivalent

#### Quick WHOIS from terminal

<CommandInput
  vars={{ domain: "domain.com" }}
